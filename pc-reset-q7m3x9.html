Clean PC Reset

Wiping a Windows 11 PC you think has malware, start to finish. Tick things off as you go. Ticks are saved on this device.

0 / 0
Golden rule: anything to do with accounts or passwords happens on a clean device (your phone or another computer), never on the infected PC. Malware often logs keystrokes, so a password you type on the infected PC should be treated as already stolen.

0 Contain it now

5 minutes · do this first

  • This cuts off anything sending your data out. Plug back in only for a step that needs it.

    • Windows Security → Virus & threat protection → Scan options → Microsoft Defender Offline scan (reboots and scans before Windows loads).
    • Write down any threat names it finds. An "infostealer" or "RAT" finding means assume every saved browser password and logged-in session is compromised.

1 Lock down your accounts

30–60 min · on your PHONE or another clean computer

  • Gmail: myaccount.google.com → Security → "Your devices" → sign out unknown devices. Email comes first because it's the reset key for everything else.

    • GitHub: Settings → Sessions (sign out others), SSH keys and Personal access tokens: delete any that lived on this PC; you'll make new ones after.
    • Revoke and regenerate any API keys that were saved in files or environment variables on this PC.

2 Back up, carefully

1–3 hrs, depending on size

Back up data, not programs. Documents, photos, project files and models are fine. Anything that runs (.exe, .bat, .ps1, .msi, installers, cracks, "portable" apps, browser extensions) gets reinstalled fresh from the official source instead.

  • Anything already pushed to GitHub or synced to MEGA is already safe. You only need what exists nowhere else.

  • Malicious ComfyUI custom nodes and pickled .ckpt/.pt/.bin models are a known way malware gets in. Reinstall the nodes you need from their official repos afterwards.

  • Windows 11 Home often encrypts the drive automatically. A wipe makes this moot, but you'll want the key if anything goes sideways mid-install.

3 Make the install USB

30 min · on a CLEAN computer · 8 GB+ USB stick (it gets erased)

No clean computer? Second best: on the infected PC go to Settings → System → Recovery → Reset this PC → Remove everything → Cloud download, and choose "Clean data". It works against almost all common malware, but the USB clean install is the more thorough option.

4 Wipe & reinstall

45–90 min

Multiple drives? If you have extra drives with data or models on them, unplug them (or be very sure which is which) before you delete partitions. Deleted partitions are gone for good.

5 Harden the fresh install

1 hr, mostly waiting on updates

6 Bring things back

As needed

7 The week after

Light follow-up

When to call a pro: if money already left an account, if your email or Microsoft account was taken over and you can't get back in, or if the same symptoms come back after a clean USB install. That last one is very rare and can point to firmware-level malware, which needs a BIOS update or professional help.
