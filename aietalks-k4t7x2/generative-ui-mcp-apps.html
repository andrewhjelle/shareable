Beyond Components: Designing Generative UI for MCP Apps

SpeakerRuben Casas · Postman Watchyoutu.be/hCMrEfPG2Yg
Product & UXMCP & protocolsAgentic engineering

If you only read one thing

  • GPT-5.2 and Opus 4.5 were the first models good enough at high-fidelity UI generation that a single prompt could rewrite a blog and add unrequested features like a working search box (c1, c10).
  • There are three levels of generative UI in use today: static components fed props (AGUI, Goose), declarative JSON/YAML descriptors mapped to static components (JSON Render), and fully generative on-demand HTML/CSS/JS (c2, c3, c4).
  • Fully generative UI needs a sandboxed distribution model because LLM-generated code shouldn't be trusted any more than third-party code, which is why MCP apps' default double-iframe sandbox matters, including for Anthropic's own first-party visualizer feature (c5, c6, c7).
01Models got good enough to write real front-end code

The speaker traces a path from late-2022 'poor man's vibe coding' (copy-pasting ChatGPT code blocks) to GPT-5.2 and Opus 4.5, which he says were the first models genuinely strong at long-horizon tasks and high-fidelity UI generation. Testing this himself on a blog rewrite, the model added an unrequested search box with a blur animation and built-in accessibility.

“It created a nice nice search box with a blur animation, with accessibility out of the box”

▶ watch at 02:08
02Three levels of generative UI

Static components are the most common approach today: the agent is purely an orchestrator that calls predefined, developer-built components with data/props, as in the AGUI protocol's client-tool-to-React-component mapping. Declarative UI is a step up, where the agent emits a JSON, YAML, or Python descriptor that a rendering engine maps onto the same static component library, as with Vercel's JSON Render tool, which the speaker calls the current 'perfect balance' of flexibility and consistency.

“They have an SDK when you can register a client tool that maps to a React component”

▶ watch at 06:50

“JSON Render is being built by Vercel. And it is a way to map your components using JSON and also YAML”

▶ watch at 08:56
03Fully generative components, and why they're risky

The next level lets the model write HTML/CSS/JavaScript on demand at runtime with no predefined components at all; the speaker built a demo weather agent at Postman that generates a joke plus full HTML/CSS/JS UI in one tool call. He argues this only becomes safe to ship with a distribution model that provides boundary, containment, and sandboxing, since generated code deserves the same distrust as arbitrary third-party code.

“this weather agent that goes to the API, the weather API. It creates a joke. It creates the HTML, CSS, JavaScript, all in one tool call”

▶ watch at 11:03

“if we don't trust third-party code, well, we should not trust um, code that has been generated by LLMs and then just present it to the user”

▶ watch at 11:34
04MCP apps as the delivery mechanism

MCP apps are sandboxed by default via a double iframe and bundle authentication, tool calling, and message passing between UI and agent, making them the default mechanism for third-party UI delivery today. The speaker points to Anthropic's own visualizer feature adopting MCP apps for first-party UI, rather than building a proprietary rendering architecture, as a strategic signal for the protocol's staying power.

“It's sandboxed by default with that double iFrame. Is the default for third-party UI delivery today”

▶ watch at 12:04

“they could have just created their own rendering um, and an architecture mechanism for delivering this in interaction in in cloud, but they decided to go with MCP apps”

▶ watch at 12:36
05Beyond components: collaborative canvases

The Excalidraw MCP app is cited as pointing past static or generative components entirely, creating a shared canvas artifact where a human and an agent can both edit the same UI back and forth. The speaker predicts the next stage of generative UI is this kind of personalized, collaborative human-agent workspace rather than a fixed chat interface or a single super-app.

“The Excalidraw MCP app does something very interesting, which it creates a a shared artifact. It creates a canvas where a human and an agent can collaborate together into a shared space”

▶ watch at 15:11

“I believe beyond components, it will be the future of generative UI will be more a collaborative experience where yes, we will have some generative UI, but that UI is going to be super personalized”

▶ watch at 15:42

Commentary (ours)

Framing MCP apps' sandbox as the enabling condition for fully generative UI (rather than a protocol nicety) is a useful lens for evaluating other 'agent writes the UI live' demos — the interesting engineering question isn't whether a model can generate a working page, but what containment model lets you ship that generated page to a real user (ours).
