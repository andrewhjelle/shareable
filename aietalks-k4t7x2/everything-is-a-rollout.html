Everything Is a Rollout

SpeakerAlex Shaw · Laude Institute Watchyoutu.be/jRCpXUjz4CI
Agentic engineeringEvals & benchmarksPost-training

If you only read one thing

  • Agent development should be treated like machine learning, not traditional software engineering, because agent output is a blackbox artifact you can't predict with 100% confidence even on simple tasks, unlike deterministic code (c1, c2).
  • Harbor standardizes the rollout loop -- instruction, sandboxed environment, verifier producing a reward -- as an open, interoperable format now used across roughly 300-400 eval and training environment sets, including several benchmarks launched the same day as the talk (c3, c4, c7).
  • Satya Nadella's framing (build the eval first, then welcome all models) matters because once you own the eval you can freely swap models instead of trusting a vendor's or a public benchmark's numbers (c5).
01Agent development is ML, not software engineering

Shaw contrasts a 2018-style regex program, whose output he can predict with 100% confidence across a million runs, with a 2026-style model-call program, where he can't guarantee identical output run to run even on a simple phone-number extraction task. He argues this uncertainty compounds as task complexity increases, making agent development structurally closer to machine learning than to traditional software engineering.

“we know now agent development is more similar to machine learning than it is to software engineering”

“if I ran this exact program one million times, I'm not 100% confident that it will print the same thing every single time or that I know exactly what it will print”

02What an environment and a rollout are

Shaw defines an environment as three parts: an instruction telling the agent what to do, a sandbox (virtual computer) for it to act in, and a verifier that determines whether the agent succeeded within a time or stopping condition. A rollout is the process of running an agent through that sandbox until a stopping condition, then passing the sandbox to the verifier to produce a reward, aggregated across many rollouts into a result.

“we need some way of telling whether or not the agent actually did the thing that we told it to do in the sandbox within some amount of time or other stopping condition”

▶ watch at 07:50
03What Harbor is and its adoption

Harbor is described as three things: a format for specifying agentic environments, an open-source framework for running rollouts in parallel with any agent, model, or sandbox, and a registry of roughly 300-400 training and eval environment sets. Shaw cites adopters including Cognition (migrated evals to Harbor), Handshake's investment-banking benchmark, Scale's Suite Atlas, Poolside, and LangChain's deep agents integration.

“it's an open-source framework for performing rollouts in parallel using any agent with any model in any sandbox on any task”

“I think we have like three or 400 Aval sets by now”

04Build the eval before picking the model

Shaw quotes Satya Nadella's advice to start any agentic system build with the eval that matters and the ability to grade the outcome, then be open to any model. He argues this ordering puts control in the builder's hands, removing the need to trust a vendor's brand or a third-party benchmark.

“if you want to build an agentic system start with the aval that matters and your ability to grade the outcome and then say I welcome all models”

▶ watch at 11:30
05Beyond eval: reward hacking and other rollout uses

Shaw maps ML concepts onto agent development, noting that overfitting in agent development shows up as reward hacking. He also describes non-eval uses of the rollout pattern, including selling task data to labs, running large-scale parallel 'agentic map-reduce' jobs (demoed live via Harbor Exec across cursor-CLI map steps and a reduce step), and feeding rollout trajectories into SFT or RL training.

“overfitting looks like reward hacking or also just uh overfitting that's also possible for agent development”

▶ watch at 06:13

“I do the map step with cursor CLI because it's cheap and fast. And then I do the reduce step with fable 5 because I wanted to have like an accurate summary and I care about intelligence in that scenario”
