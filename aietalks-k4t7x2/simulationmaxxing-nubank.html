SimulationMaxxing: How we ship agents 20x faster

This talk gives production evidence for teams deciding whether to invest in simulated eval data versus waiting on production traces or hand-authored data to evaluate customer-support agents

If you only read one thing

  • Generating eval data in simulation instead of waiting on production data let Nubank ship agents 20x faster, cutting release cycles from weeks to hours.
  • 80% of domain-expert labels confirmed simulated conversations are usable data, and one agent's customer-satisfaction score (TNPS) doubled while self-service rate improved by up to 4% in one case.
  • Recommendation: simulation only pays off if teams close the sim-to-real gap with offline, online, and human-review metrics that verify sim data tracks real production data.

The bottleneck: eval data, not metrics

  • Nubank frames agent evals as two problems: metrics and data.
  • Metrics have a known playbook (LLM-as-judge classifiers aligned to human judgment), but generating the multi-turn trajectory data to run those metrics on is expensive and slow, whether authored by hand or scraped from production traces, and that data problem is the real bottleneck to fast iteration.

“we have verified in production that yes simulations circuit this timeline short circuit this timeline from a few weeks you can go to less than a day sometimes even a few hours a few minutes”

02Simulation short-circuits the release cycle

Simulation short-circuits the release cycle

  • Nubank's core claim is that generating eval data in simulation instead of relying on production data lets teams ship agents 20x faster.
  • Where changing an agent harness, running offline evals, and waiting for a statistically significant production A/B test could together take weeks, simulation-driven iteration on the harness and evals now happens in hours.

“If you generate your eval data in sim instead of waiting on production data you can ship agents 20x faster and we'll give you evidence for that.”

said at 01:04
03Validating sim against real production data

Validating sim against real production data

  • Nubank checked whether simulated conversations are trustworthy substitutes for real data by comparing eval quality on simulated versus real data and running human review: domain experts confirmed 80% of sim-derived labels were usable, for both mature agents and new agents built from scratch.
  • The team recommends this offline/online/human-review validation step before trusting simulation results.

“we had human review done where 80% of our domain expert labels confirmed that sims give us usable data not just for uh mature agents but also for green field agents.”

said at 11:22

“you really need to close out the sim toreal gap. So you need to you know set up like offline online human review kind of metrics to really understand how sim performs visav real production data”

04Production results

Production results

  • Nubank reports simulation caught a regression before it reached production, doubled TNPS (customer satisfaction) for one agent, improved self-service rate by up to 4% in one case without trading it off against satisfaction, and cut multiple weeks off the process of testing open-source model options in the agent harness.

“one of our agents, the TNPS, has 2xed uh thanks to simulation, robust evals, and investing in something super principled rather than, you know, throwing something at the wall and see what sticks.”
