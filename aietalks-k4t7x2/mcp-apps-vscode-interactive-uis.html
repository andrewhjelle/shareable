Building Interactive UIs in VS Code with MCP Apps

SpeakerMarlene Mhangami & Liam Hampton · GitHub / Microsoft Watchyoutu.be/_xIwFcnHqp4
MCP & protocolsProduct & UXCoding agents

If you only read one thing

  • MCP apps let a server tool return a resource reference to bundled HTML that the host (e.g., VS Code) fetches and renders as an interactive component inside a sandboxed iframe in chat, instead of returning only text.
  • Companies already building MCP apps include Shopify (in-chat checkout matching brand UI), Excalidraw (interactive diagrams), and Figma.
  • The live demo used a custom MCP server exposing one tool that profiles a Go program and renders its flame graph as an interactive React app inside GitHub Copilot Chat; the iframe sandbox exists specifically so the rendered app can't touch VS Code settings or call external APIs.
01MCP basics: hosts, clients, servers

MCP is described as an open protocol, created by Anthropic, that standardizes how applications provide context (tools, prompts, resources) to LLMs. Hosts like VS Code want data from MCP servers, clients (in VS Code's case, GitHub Copilot) maintain the one-to-one connection to a server, and servers are lightweight programs exposing specific capabilities. The speakers warn that installing a random internet-sourced MCP server can carry security risk and recommend using vetted server lists inside VS Code or GitHub.

02MCP apps: rich UI instead of text-only output

Early MCP could only return text, which the speakers say pushed READMEs toward ASCII art and heavy emoji use as a substitute for real diagrams. MCP apps solve this: a server tool returns a UI resource reference pointing to server-generated HTML, the host fetches that HTML and renders it inside a sandboxed iframe, and the app can call back to the server for live, two-way interaction and fresh data.

“MCP apps let server tools return rich interactive components that render directly in the chat”

“the host, which is VS Code, is going to fetch the HTML from that UI reference that was referenced from the server, and then the host is going to render the app inside a sandboxed iframe”

03Use cases and current adopters

Cited use cases include data exploration (clicking through charts instead of re-typing questions) and e-commerce, where a user could complete an entire checkout inside the chat instead of being handed a link out to a browser. Shopify is named as a company building MCP apps specifically to preserve brand-matching UI during in-chat checkout, alongside Excalidraw (diagram generation) and Figma.

“I think this is a really great example where a user maybe in one case would want to be able to actually buy something in the chat UI”

“they're also focusing on keeping the brand experience of a company the same as if you were on the company's website”

04Live demo: a flame-graph MCP app in VS Code

The demo used a custom MCP server, adapted from an Anthropic skill, exposing one tool that profiles a Go program (bubble sort and Fibonacci) with Go's pprof over five seconds and returns results rendered as an interactive React flame-graph app inside GitHub Copilot Chat. The presenter explains the iframe sandbox using a 'hamster in a cage' analogy: the rendered app is deliberately prevented from interacting with VS Code settings, APIs, or anything external.

“I have it installed here, and there is one tool for it. So, profile the app”

“The reason we're doing this in an iframe or the why the iframe is the same reason that you put a hamster in a cage, right? If you don't let it loose in a room, it's just going to chew things up”
