One thesis stated, one acted out

Anthropic says it outright: harnesses are now the limiting factor on what models can achieve. The OpenAI talk never makes that claim — it just spends its whole slot on harness mechanics and barely a word on model quality. Where they genuinely differ is the ecosystem bet.

Trend signals from the flagship pair (ours, from the claims graph)

  • Harness features migrate downward - into the API (OpenAI) or the managed platform (Anthropic). If that holds, hand-rolled agent loops age into legacy code.
  • Judgment work is being delegated to sidecar agents (safety review, completion grading) rather than to humans-in-the-loop.
  • Caveat on all of the above: n=2, and both speakers sell the alternative to hand-rolling. Directional signals, not laws.
02The corpus read — 430 claims across 52 talks

What the corpus agrees on — and where it splits

Every statement below is backed by independent claims from separate talks (linked ids resolve in each brief’s claims table). Convergences require multiple companies arriving at the same answer; a “divergence” must be a real disagreement, not a different topic.

Convergences (multiple independent talks)

  • Harness engineering, not model choice, is the working leverage point. a domain-tuned harness beats a generic one on the same model, and matches frontier-model judging at 1-2 orders of magnitude lower cost. agents·c2 improving·c3 dark·c9 memory·c5 as4
  • Sidecar judges are becoming the standard QC layer in every domain. live-traffic judges in health AI, clinician-rubric LM judges, hazard judges, token-selection judges in distillation, review-comment registries in code. guardrails·c6 ambient·c5 shipping·c6 ai·c7 continual·c8 kill·c5 as9 cx5
  • Model alignment is not a security boundary. Enforcement is moving outside the model: byte-level network proxies, scoped short-lived credentials, deterministic code layers above the model, zero-trust object storage. security·c1 guardrails·c5 it·c6 unlock·c3 enterprise·c5
  • Anything tuned to today's model rots at the next release. fine-tunes regress, harness workarounds become dead weight, evals go stale, and a better-benchmarked model can be worse for your system. fine·c2 fine·c5 agent·c1 agent·c7 healthcares·c2 as1
  • Continual learning / accumulated expertise is framed as the next scarce axis now that raw intelligence is abundant - a whole conference track plus practitioners converging on it independently. intelligence·c7 scaling·c5 improving·c7 compound·c6

Live disagreements

  • Whether humans keep reading diffs is genuinely contested. one camp moves review to intent + verification evidence (30% of changes already merge unreviewed), another insists you never ship code you haven't personally read. kill·c7 kill·c2 prototyping·c8 ai·c7 last·c3
  • Two independent evaluations found leaving context alone beats compaction (recall dropped to 32% after compaction; plain in-context learning beat memory machinery) - while both big labs ship compaction as core infrastructure. Scope matters: the evals tested recall within window limits; the labs engineer for runs that exceed them. context·c1 context·c5 context·c9 evaluating·c6 cx6 as10

Trend signals (ours, hedged)

  • Agent-generated data is predicted to eclipse all human-produced data on shortening timescales (n=2 talks - directional, not law).
  • Vertical-AI moats are claimed to be domain experts + proprietary data, never the model (n=4 talks across health, pharma, trading).
  • Costs quoted for agent work keep collapsing: 75x cheaper CLI vs MCP, 100x cheaper real-time video vs batch, 1-2 orders cheaper judging via harness work. Vendor-stated numbers; treat as direction.
