If you only read one thing

  • Gemma 4 ships in four sizes -- two on-device effective models, a 26B MoE with 3.9B active parameters, and a 31B dense model -- with the 31B and 26B both ranking in the top six of open-source models on LM Arena, all under an Apache 2.0 license.
  • Attention changes include a 5:1 local-to-global layer ratio, 512/1,024-token sliding windows, and grouped-query attention (2 queries per KV head locally, 8 globally) to cut serving cost on the expensive global layers.
  • On-device models store per-layer embedding tables in flash memory instead of VRAM, and vision now handles variable aspect ratios/resolutions directly instead of Gemma 3's pan-and-scan image splitting.

Four model sizes, one license

03Attention efficiency changes

Attention efficiency changes

  • Gemma 4 introduces a 5:1 ratio of local to global attention layers (4:1 in the smaller effective model), with sliding windows of 512 tokens in smaller models and 1,024 in larger ones.
  • To offset the cost of the still-expensive global layers, Gemma 4 uses grouped query attention: two queries share a key/value head locally versus eight queries sharing one globally, with the global key/value head length doubled to 512.

“What we've done with Gemma 4 is we've made several improvements within attention. We've introduced a 5:1 ratio of interleaving local to global layers”

04MoE routing and on-device memory tricks

MoE routing and on-device memory tricks

  • The 26B MoE model has one shared router expert plus 128 total experts, with eight activated on each forward pass.
  • Separately, the on-device effective models store their per-layer embedding (PLE) tables in flash memory rather than VRAM, since VRAM is one of the largest constraints on phones and laptops.

Vision handling improves over Gemma 3
