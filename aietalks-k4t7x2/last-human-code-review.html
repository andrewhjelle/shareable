The Last Human Code Review: Building Trust in AI-Generated Code

SpeakerItamar Friedman · Qodo Watchyoutu.be/s-aixZYJG4c
Coding agentsContext engineeringSecurity

If you only read one thing

  • Friedman splits engineering orgs into two camps: those requiring human review of every line, and those that ship fast and fix bugs after they reach production (c3)
  • He argues code-review model quality has plateaued — the real bottleneck is fragmented context (agents.md, tribal knowledge, Slack threads) with no shared governance layer (c1, c4)
  • Teams already shipping AI-generated code faster than humans can review it are not ahead of the curve — they're already exposed, unless the context and governance layer is built first (c5)
01Two camps on AI-introduced bugs

Friedman poses to the audience whether human review of every PR diff will still be mandatory by the end of 2026. He describes two schools of thought he heard from engineering leaders: one insists every line must be human-trusted before it ships, the other accepts that bugs will reach production and get fixed quickly afterward because velocity matters more.

02Context, not model quality, is the real bottleneck

He argues that code-review model benchmarks haven't moved much across recent model generations — the limiting factor is context. Teams' rules and standards are scattered across agents.md, cloud.md, skills.md, and Slack threads with no shared source of truth, which he calls a missing governance layer standing between current tooling and trustworthy automated review.

03Why shipping faster than you can review is a trap

Teams that are already shipping AI-generated code faster than humans can review it are not ahead, according to Friedman — they're already in the problem, unless they've built the context infrastructure needed to automate review safely.

04Where this is headed

Friedman frames the end state as moving from artificial intelligence to what he calls artificial wisdom — codifying the judgment senior developers currently hold in their heads so both agents and humans can act on it. Qodo's stated target is reaching 2027 with zero outages and zero critical or high-severity production bugs.
