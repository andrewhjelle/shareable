While My Guitar Gently Speaks

A concrete build order for a personal generative-audio/instrument project: text-to-speech sliced per word, pitch detection driving a vocoder, offline pitch-shifted vocal samples for singing, and a live Whisper-to-local-LLM-to-instrument ...

If you only read one thing

  • Built a DAW plugin that converts typed text to speech and plays it back per guitar note, using energy-gap segmentation to slice audio into words — a method that fails when speech has no silence between words (c1, c2).
  • Layered on YIN pitch detection and a vocoder so a played guitar note reshapes a synthesized voice into singing in real time (c3, c4).
  • Added an offline path using the World pitch-shifting library on pre-recorded vocal samples for more natural singing (too heavy to run live), plus a conversational mode: mic to Whisper to local LLM to guitar voice (c5, c6, c7).

Building the plugin

  • The project started as a Logic Pro plugin built with audio tooling like JUCE, chaining text-to-speech (Piper and built-in Apple TTS) so that typed text is converted to an audio clip and played back whenever a guitar note is struck.

02Slicing speech into playable words
Slide at 08:20 · click any slide to enlarge · 5 more from this section below

Slicing speech into playable words

  • Playing back a whole sentence per note wasn't enough, since a language has more than one word, so the next step was slicing the audio per word.
  • The approach was energy-gap segmentation: cut wherever decibel levels drop close to zero.
  • That method is not fully reliable because normal speech often has no silence between words, so it was combined with a syllable-detecting "sonority peak" approach and backed by manual drag-to-edit correction of the segments.

“the decibels are are very much close”

03Making the guitar sing
Slide at 10:20 · click any slide to enlarge · 8 more from this section below

Making the guitar sing

  • To move from speaking to singing, the project added pitch detection using the YIN algorithm to find the fundamental frequency of a played guitar note, generate a synthesized pitch (with ADSR shaping), and push that synthesized note through a vocoder along with the voice clip so it sings the note.

04Getting real vocal texture

Getting real vocal texture

  • For a more natural singing tone, the project used open vocal recordings from the VocalSet dataset and the World pitch-shifting project to shift a singer's recorded samples to match each guitar fret/note.
  • This pitch-shifting process is too heavy to run live, so the samples have to be pre-baked offline before they can be jammed with in real time.

05From talking to conversing

From talking to conversing

  • The last step made the interaction conversational: speak into a microphone, transcribe with Whisper, run the text through a local LLM to generate a reply, and play that reply back on the guitar the same way.
  • The talk closes with a call for the audience to go build their own passion-project ideas, arguing AI has made that kind of building much less of a time sink than it used to be.

Commentary (ours)

(ours) The pre-bake requirement for the vocal-sample singing path is the load-bearing constraint in this build: real-time pitch-shifted vocal synthesis wasn't fast enough to run live, which is the kind of latency tradeoff that shows up in most projects chaining STT/TTS with heavier DSP or sample-based synthesis.
