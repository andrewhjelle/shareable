If you only read one thing

  • LLMs are a closed box incapable of continual learning without forgetting, so most agent tooling (including how models themselves are trained) functions as a temporary band-aid around that limitation (c1, c2).
  • Larger context windows enabled most recent gains in long-running agentic tasks, but total world knowledge doubles roughly every 12 hours, so context will never be 'enough' -- the real challenge has shifted from getting context in to keeping noise out (c3, c4).
  • Constraints breed creativity: McLean's own CV built in plain HTML outperformed a complex custom application by roughly 10x, illustrating that models default to unnecessarily complex solutions unless deliberately constrained (c5).

LLMs are a closed box, not a learning system

  • McLean argues LLMs still don't understand the data they're presented with despite appearing advanced, citing limitations like poor data efficiency relative to humans and the inability to continuously learn without forgetting.
  • He frames most agent tooling, and even how models themselves are trained, as band-aids around these constraints: temporary, superficial fixes that mask symptoms rather than solve the underlying problem.

“no matter how advanced LLMs seem, today's large language don't actually understand the data they're presented with. And we know this cuz they've still got several clear limitations”

03Context is a soft constraint, and it will never be enough
Slide at 06:40 · click any slide to enlarge · 8 more from this section below

Context is a soft constraint, and it will never be enough

  • McLean says most recent agentic capability gains come from increased context windows enabling longer-running tasks (storing history of actions, tool outputs, goals and plans), but argues total world knowledge doubles roughly every 12 hours so context windows will never be sufficient.
  • He treats context more as a soft constraint than a hard guardrail, and says the practical challenge has shifted from getting enough context in to filtering noise out, including keeping promotional/SEO-optimized content from crowding out genuine consumer information.

“most recent advances in agentic capabilities have been largely due to increased context window. This is especially true with like long-running agents because the longer context windows allows them to do longer running tasks”

said at 06:42

“the total knowledge in the world keeps doubling about every 12 hours, so we're always going to want more”

said at 07:43
04Constraints produce creativity
Slide at 11:40 · click any slide to enlarge · 7 more from this section below

Constraints produce creativity

  • McLean advocates deliberately self-imposing constraints -- asking how little context window you can use and still complete a task -- rather than defaulting to maximal context.
  • He illustrates with his own CV: a complex custom application underperformed a version built in plain HTML by roughly 10x, and argues models are naturally verbose and tend toward unnecessarily complex solutions unless reined in.

“it was I was pretty uh blown away by this. So that was over a 10x improvement. I'd say it's probably a 100x improvement”

said at 11:51

Commentary (ours)

The 'context as soft constraint, not hard constraint' framing is a useful reversal of the usual context-engineering advice to just add more retrieval -- McLean is arguing the harder skill is subtraction, which tracks with his separate point about noise/SEO pollution in tool outputs (ours).
