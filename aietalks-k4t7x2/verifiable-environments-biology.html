Verifiable Environments for AI in Biology

SpeakerKenny Workman · LatchBio Watchyoutu.be/3ZMUiFaQ3qg

01Data scale is forcing agentic tooling onto biology

Single-cell and spatial biology experiments generate two to six and up to seven terabytes per run respectively, more than a scientist can store on a laptop, and this throughput is projected to keep rising. LatchBio, originally a data infrastructure vendor for biotech and pharma, moved toward building agent products on top of this data as coding models became capable of automating analysis.

“Single cell experiments can yield two to six terabytes per run. Spatial runs can yield seven terabytes of run”

▶ watch at 01:33
02The core thesis: data analysis as a verifiable substrate, like code

Workman's framing is that just as code gave a verifiable substrate for otherwise-unverifiable software tasks, structured data analysis can do the same for biology, turning an otherwise fuzzy scientific claim-making process into something benchmarkable and trainable.

“just like code provided a verifiable substrate for complex software tasks that are not inherently verifiable, uh data analysis might do the same thing in bio”

▶ watch at 03:04
03Frontier models aren't there yet, so LatchBio built a benchmark

Early agent prototypes on biology data showed signs of working but were unreliable; frontier models lack the combined capability of biology knowledge, coding, and domain reasoning needed for real scientific work. Existing benchmarks tested Q&A knowledge rather than the specific experiment-analysis tasks LatchBio's agents needed to do, so the team built SpatialBench, releasing 146 problems last December, borrowing structure from SWE-bench (data node, task prompt, grader config, deterministic Python grader).

“frontier models cannot be trusted to do real work. They're missing some capability between knowing biology and writing code”

▶ watch at 05:38

“It's called spatial bench. Um last December, there's 146 problems”

▶ watch at 07:39
04Ground-truth construction has to account for multiple valid paths

Because science doesn't admit one clear ground truth, a task built around a single expected answer can wrongly fail a model that took a different but equally valid analysis path. LatchBio's response is to require durability: reasoning about invariants that hold across different valid analysis paths, plus a round of human scientist cross-verification after early trajectory review revealed many of their original task assumptions were flawed.

“if you are lazy with your ground truth construction of the task, a possible valid analysis path can come with the correct answer, um and you'll fail it uh incorrectly”

▶ watch at 09:12
05Long-horizon tasks and a biosecurity gap

LatchBio extended the benchmark to long-horizon tasks simulating full paper results sections or drug-program go/no-go decisions, each taking a three-person team about a week to build; on the hardest of these (e.g., reconstructing a tumor's metastatic seeding niche), no model gets it right yet. In a separate biosecurity evaluation pairing routine tasks with red-team tasks disguised as innocuous requests (e.g., mislabeling a toxin as GFP), the routine tasks are used far more often than the red-team ones.

“None of the models get this right. Um but they're getting there”

▶ watch at 12:51

“We found that the routine tasks like drastic get drastic used drastically more frequently than the red team tasks, which is uh not great”

▶ watch at 16:26

Commentary (ours)

LatchBio built and grades its own benchmark that frontier labs then get measured on and compete over, which is a useful incentive alignment for LatchBio's product but also means the benchmark's difficulty and scope are set by a vendor with a stake in the outcome (ours).
