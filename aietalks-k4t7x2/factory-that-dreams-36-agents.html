The Factory That Dreams: 39 AI Agents, No Framework

SpeakerRushabh Doshi · Machinecraft Watchyoutu.be/jtzh-GBXBWc
Agentic engineeringMemoryData curation

If you only read one thing

  • The system uses 36 specialized single-job agents instead of one general-purpose prompt, coordinated over 213 tools exposed through one protocol, with a hard rule that agents draft and a human always sends.
  • No model was trained or fine-tuned; the system is built entirely from off-the-shelf models reading chunked historical documents (quotes, drawings, emails) stored as vectors and a relationship graph.
  • An agency quoted $230,000 to build the system; it was built in-house for about $30,000 and runs on a couple thousand dollars a month, including layered memory and a nightly 'dream cycle' that consolidates facts and resolves contradictions.
01One founder's company knowledge lived in three heads

The speaker frames the problem as institutional knowledge (customer history, past quotes, custom machine tweaks) existing only in the heads of three generations of family owners, with knowledge lost every time an employee left. The response was to build a system of 36 specialized agents that runs the company's go-to-market work, rather than a single chatbot.

“we ended up building a 36 AI agent that runs our entire go-to-market”

▶ watch at 00:00
02No training, no GPUs, just organized memory

The system was built without training or fine-tuning any model. Years of company documents (quotes, drawings, payment schedules, emails) were chunked and processed by off-the-shelf models to extract facts, which were then stored as vectors and as a relationship graph. All 36 agents' capabilities are exposed as 213 tools through a single protocol, and the enforced rule is that the agent system only drafts output; a human sends it.

“We never trained a model. No GPUs humming in the basement, no fine-tuning.”

03Engineered memory layers, including a nightly dream cycle

Memory is built in explicit layers: working memory for recent context, pinned facts, whole conversations stored as episodes, and relationships that grow from stranger to trusted. A 'salience gate' filters what's worth remembering at all, and each night a sleep cycle replays the day's activity, consolidates useful information, checks for contradictions, and discards stale data, producing a morning summary of what was learned.

“A salience gate that decides what's even worth remembering, so the brain doesn't fill up with junk.”

▶ watch at 06:41

“Every night, Eira runs a sleep cycle. It replays the day, locks in useful stuff, hunts for contradictions, gently forgets the stale junk”

▶ watch at 07:12
04Cost: a fraction of the agency quote, open-sourced as Brain OS

An outside agency quoted $230,000 to build the system; the company built it in-house for about $30,000, and it runs on operating costs of roughly a couple thousand dollars a month. The architecture has been extracted and released as an open, blank starting framework called Brain OS for other companies to populate with their own data.

“An agency quoted us 230 grand to build this. We built it for around 30.”
