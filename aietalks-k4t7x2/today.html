Harness beats model, and April sharpens the case · 2026-08-22

The 112 briefs added since the Aug 21 build all push the same way: the leverage is in the system around the model, and April's newly-fetched talks make it operational. Cloudflare's Code Mode collapses 2,600 API endpoints from 1.2M tokens of tool definitions to about 1,000 tokens by replacing JSON tool-call back-and-forth with one search-and-execute code tool in a V8 isolate; the MCP author himself now recommends the same script-in-sandbox pattern and announces Anthropic will ship skills over MCP. On review capacity, Legora calls planning-and-reviewing the new bottleneck, Ronacher says producing power vastly outruns reviewing power, an OpenAI harness engineer says hiring is GPU-and-token-limited, and Linear reports 10% of its bugs already fixed by single-shot AI with no engineer involved. What the April set adds that July and August did not: the sandbox-plus-gateway pattern told from three named vendor sides (Cloudflare, Anthropic, Amplifon), and a sharper context-ceiling number, a working 'dumb zone' near 100K tokens regardless of a 1M or 200K advertised window. Extrapolation (ours, hedged): if these fixes generalize, H2 2026 rewards commodity gateway plus skills-as-transport plus per-user sandbox as a standard stack, and penalizes teams still doing one-to-one REST-to-MCP conversions.

  • New: Agent runs that survive hours-to-days of unsupervised work are pulling checkpointing and event-sourced durability into the harness stack (now n=8 of 459 talks). We read this as: the interesting engineering primitive of 2026 is not the model call, it is the resumable session around it. If this holds, expect commodity infra vendors to ship 'durable agent runtime' as a first-class product line (ours).
