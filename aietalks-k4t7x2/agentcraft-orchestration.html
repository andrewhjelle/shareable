AgentCraft: Putting the Orc in Orchestration

SpeakerIdo Salomon · AgentCraft Watchyoutu.be/kR64LOqBBCU
Agentic engineeringCoding agentsProduct & UX

If you only read one thing

  • AgentCraft renders each coding agent's work as a map of your file system, with directories as areas and files as rooms, so collisions can be seen and flagged before they happen (c3, c4).
  • A 'campaign' feature lets an agent decompose and run a broadly-stated task inside a container without babysitting, shifting the human's effort from monitoring to planning and review (c5).
  • Shared workspaces extend collaboration from human-to-agent to human-to-human: one person can see a teammate's agent and continue its work from where it left off (c6).
01The orchestration bottleneck is the human, not the agents

The talk opens by arguing that spinning up dozens of parallel coding agents is easy, but the human staring at the resulting screen of agents is the actual bottleneck. Salomon frames this as an unfamiliar management problem -- engineers don't normally manage dozens of workers -- and argues the needed skill already exists in real-time strategy gaming, where managing many units at once is routine.

“if one agent is so amazing, why don't we scale up to 10 or 20 or 100 different agents and be 100 times more amazing”

“the role of the engineer to actually go and manage dozens of reckless employees is not typically what we do in most companies”

02Turning the file system into a map

AgentCraft visualizes a live coding agent (Cursor, Claude Code, Codex, etc.) as a physical unit on a map that is a direct projection of the user's file system: directories become areas, files become rooms. Because the tool tracks which agent touched which file and when, it can build a heat map to flag potential collisions between agents proactively.

“if we look at the map, you would notice that it's actually a projection of my file system”

▶ watch at 03:39

“I can actually track and see visually what the agent is working on, which file”

▶ watch at 04:10
03Reducing the babysitting loop

Beyond visibility, the tool borrows an RTS mechanic -- using muscle memory to quickly cycle attention between agents that need approval or answers. To reduce babysitting further, a 'campaign' feature lets the user state a goal broadly, spin up a container, and let the agent decompose and run the task without direct supervision, moving effort into planning and review instead of monitoring.

“if agents are so amazing, why not just let them do it? I can just like give them some idea”

▶ watch at 05:41

“we can lean into another cool mechanism from RTS games. We can simply use muscle memory to quickly cycle between the agents that need our help”

▶ watch at 04:40
04Working alongside teammates, not just agents

AgentCraft also supports shared workspaces where a human can see a teammate's agent activity and hand off work between people's agents -- described as the tool's favorite feature, extending the orchestration model from human-to-agent to human-to-human collaboration mediated by agents.

“is that we can actually create these workspaces. So, I can collaborate with the product designer from my team and they can do whatever they want”

▶ watch at 07:45

Commentary (ours)

(ours) This is a live demo of Salomon's own product, presented free and still described as experimental; no metrics were given on time saved, defect rates, or how the collision heat map performs at scale, so treat the workflow claims as a vendor walkthrough rather than an independently measured result.
