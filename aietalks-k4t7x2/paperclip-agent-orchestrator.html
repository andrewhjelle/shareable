If you only read one thing

  • Paperclip crossed 40,000 GitHub stars roughly 34 days after its March 4th open-source release (c1, c2).
  • It's positioned as a vendor-neutral orchestration harness across agent providers (Claude, Codex, Gemini, and others) and explicitly not a coding or code-review tool (c3, c4).
  • It tracks monthly spend and lets you set budgets per agent and per project, and can route lower-stakes agents to cheaper or free models via OpenRouter, but as demoed still lacks multi-user support (c5, c6, c7).

02A vendor-neutral harness, not a coding tool

A vendor-neutral harness, not a coding tool

  • Paperclip is built to let any agent provider (Claude, Codex, Gemini, and others) be brought in as an 'employee,' explicitly because hooks and behavior differ between harnesses like Claude and Codex.
  • The speaker is emphatic that Paperclip itself is not a coding tool or code-review tool but a general orchestration layer for running a business.

“paperclip gives you this kind of vendor-neutral harness where you can create these higher-level workflows”

said at 10:24

“the important thing I want you to understand about paperclip is that it is not a coding tool. Paperclip is not a code review tool. Paperclip is designed for creating uh businesses”

said at 12:57
03Cost controls: budgets and model routing

Cost controls: budgets and model routing

  • The product tracks monthly spend and supports setting budgets per agent and per project.
  • It also integrates with OpenRouter so lower-stakes agents can be assigned cheaper or free models rather than paying frontier-model prices for every agent.

“paperclip is it does keep track of your monthly spent. You can set budgets per agent and budgets per project”

said at 19:13

“The Quinn 3.6 plus is actually free right now. So you could hire an agent that uses Quinn 3.6 plus”

said at 17:39
04Known gap: no multi-user support

Known gap: no multi-user support

  • As demoed, Paperclip does not yet support multiple human users working on the same organization, which the speaker calls a huge gap and says is actively being worked on.

“there's not multiple human users. That is a huge gap. We are working on this feature really this week”

said at 22:20
05Advice for new users

Advice for new users

  • The speaker recommends starting with only the agents you actually need rather than importing large template organizations (he cites a 130-agent template as an example), arguing that under-specified agent behavior produces poor results.

“My suggestion for you when you're just getting started with agents is just start with the agents that you need”

said at 16:37
