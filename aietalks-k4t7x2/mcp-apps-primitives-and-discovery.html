Explains the current MCP apps primitives (sandboxed-iframe widgets, set-state, send-follow-up-message, dual UI/model outputs for privacy) and, more importantly, the store submission and dynamic-discovery mechanics on Claude, ChatGPT, and...

If you only read one thing

  • MCP apps became the official Model Context Protocol extension in January 2026, letting MCP servers return sandboxed-iframe UI widgets instead of just JSON (c2, c3).
  • Widgets can update model state, send follow-up chat messages, and return separate UI-only vs. model-visible outputs so private information shown to the user isn't necessarily sent to the model (c4, c5, c6).
  • Claude, ChatGPT, and Cursor all support self-serve MCP app/server submission with one-click install, and Claude already does dynamic discovery -- searching the MCP registry for the right connector when no specific tool is assigned -- with ChatGPT expected to follow (c8, c9).

Manufact's SDK reach and the MCP apps timeline

  • The speaker's company builds open-source MCP SDKs (MCPUI, now with 8 million+ downloads and 10K GitHub stars) and an MCP cloud platform.
  • MCP launched in 2024; MCPUI began mid-2025 as a way for MCP servers to return UI components; ChatGPT released an app SDK and Character AI and Claude quietly opened MCP stores at the end of 2025; in January 2026 MCP UI converted into MCP apps, the official Model Context Protocol extension for returning UI elements.

02How an MCP app works

How an MCP app works

  • In an MCP app, the MCP server returns a widget rendered in a sandboxed iframe instead of a JSON string, with bidirectional communication between the iframe and the host application via declared UI resources populated by tool arguments.

“the MCP server in this case doesn't return a JSON string again, but it returns a widget in a sandboxed iframe”

said at 06:15
03Widget primitives: state, messages, and privacy-preserving outputs
Slide at 08:10 · click any slide to enlarge · 8 more from this section below

Widget primitives: state, messages, and privacy-preserving outputs

  • Widgets can call a set-state primitive to update what the model knows about UI changes, and can trigger a send-follow-up-message primitive to push a message into the chat -- though Claude puts it in the chat input for the user to choose to send, while OpenAI sends it directly to the model.
  • Tools can also return two separate outputs: a structured output sent to the widget for the user to see, and a separate output sent to the model, letting private information be shown in the UI without being disclosed to the model.

“the protocol mandates this state uh or this set state primitive where you can update the state of the model with respect to the UI components”

“Cloud will display the message in the chat input and tell the user like the user has the choice to send it or not. While OpenAI is a bit more integrated in this sense, it directly sends the model the message to the model”

said at 10:25

“there is a structured output, which is sent into the widget itself. And there is an additional output that can be sent directly to the model”

05Dynamic discovery is the bigger shift
Slide at 24:30 · click any slide to enlarge · 4 more from this section below

Dynamic discovery is the bigger shift

  • Beyond store search and one-click install, Claude already performs dynamic discovery: when assigned a task with no specific tool, it searches the MCP registry for the right connector.
  • The speaker says ChatGPT is expected to add the same capability soon, and cites Paul Graham's statement that AI apps are the new browsers as framing for why store presence matters.

“when Cloud needs is like assigned a task that doesn't have a specific tool to do, it will actually search in the MCP registry for the right connector to do the task”

Commentary (ours)

Dynamic discovery -- an agent auto-selecting your connector without the user ever searching for it -- is the detail most likely to be underrated; it turns MCP store presence into an acquisition channel comparable to SEO for the agentic era, but only Claude does it today so the payoff is still speculative for most builders (ours).
