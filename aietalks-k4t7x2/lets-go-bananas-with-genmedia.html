Let's go Bananas with GenMedia

SpeakerGuillaume Vernade · Google DeepMind Watchyoutu.be/BcWFc3H7Khg
Generative mediaInfra & servingProduct & UX

If you only read one thing

  • DeepMind ships new Gen Media capabilities on average more than once a month; current pricing includes Veo 3.1 Light at about 5 cents per second (roughly 40 cents per video) and Lyria's 30-second clip model, cheaper than its up-to-3-minute full-song model which costs twice as much.
  • A new priority service tier (shipped the week of the talk) lets requests pay twice the price for guaranteed speed, while a flex tier gives a 50% discount in exchange for possible delays of a few minutes; the newer Interactions API also lets a client reuse a server-side interactions ID instead of re-uploading full context on every call.
  • Preview models are restricted to global endpoints by Google Cloud policy, which the speaker names as the core reason EU customers with data-residency requirements remain limited to older, generally-available models.

03New APIs and how video/music models are trained

He introduces the newer Interactions API, which returns a reusable interactions ID so a client can recover prior context from the server instead of re-sending it on every call. He also explains that video generation models are trained heavily on image generation, because producing the correct first frame is treated as the most important part of generating a video.

“every time you you make a call, you get an interactions ID. And you can reuse that interactions ID in future calls and it will recover all of the all of the context directly from the server.”

04EU access limitation

Responding to an audience question about being stuck on an older model for EU-hosted deployments, he attributes the restriction to a Google Cloud rule that every preview model is available only on global endpoints, which he calls unlikely to change even as the team tries to shorten how long models stay in preview.

“the core of the problem in a way it's the rule that uh at Google Cloud that every preview model is only available on global endpoints”
