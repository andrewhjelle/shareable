Agent Output Is Not UX: Rendering Layer Your LLM Pipeline Is Missing

SpeakerBala Ramdoss · Amazon Lens Watchyoutu.be/maTp79FD9gI
Product & UXAgentic engineeringContext engineering

If you only read one thing

  • The model already does the reasoning work; the gap that decides whether users can act on it is the rendering layer between model output and screen (c1).
  • Mobile clients can't be patched after an unrecognized UI type ships, so the model must be given a fixed, version-aware menu of components rather than allowed to invent one (c3, c4).
  • Streaming typed UI blocks (not text) and chasing time-to-first-chunk instead of total latency changes what's measured and what feels responsive (c2, c5).
01The model isn't the bottleneck, delivery is

Ramdoss opens with an AI assistant that correctly answers a restaurant-booking question but leaves the user to still do the work of booking. He argues the model already does the real work; the layer between model output and something a human can act on, not the model itself, is what determines whether an agentic product succeeds.

“The model did the real work, but look at the outcome. I have to do my research and work towards actually booking the table.”

▶ watch at 00:15
02Generative UI: the model describes UI as data

He introduces generative UI and Google's open A2UI spec as a shared vocabulary for a problem he used to solve bespoke each time: instead of returning raw text or HTML, the model describes UI as a list of typed components that the client renders with native widgets. He places this on a control spectrum from fixed pre-built components to fully open-ended generation, noting most production mobile apps stay in the safer, lower end of that spectrum.

“Instead of the agent handing you a raw text or HTML, it describes the UI as data. A list of components and the client renders them with its own native widgets.”

▶ watch at 03:08
03Mobile clients cannot be patched, so give the model a fixed menu

Unlike web, mobile apps can't ship a fix in minutes; an unrecognized content type causes the app to crash repeatedly for users on old versions rather than degrade gracefully. His fix is a version-aware rendering contract: the model is only ever allowed to choose from a fixed, versioned menu of UI components it's told the client supports, never invent a new one.

“You cannot meaningfully patch the client.”

▶ watch at 05:43

“notice what the model never does. It never invents a component. It chooses from a fixed menu that you provide to it.”

▶ watch at 07:51
04Stream typed UI blocks and measure time-to-first-chunk

Because LLM latency plus safety checks make waiting for a full response impractical, Ramdoss recommends streaming UI in chunks (skeleton, partial, complete) rather than one blocking response, and switching the core latency metric from total response time to time-to-first-chunk. He also recommends showing the agent's in-progress state sparingly, since users now expect visibility into what an agent is doing rather than a bare loading spinner.

“You stop chasing the total latency, which we have done for over a decade. You start chasing time to first chunk.”

▶ watch at 09:26

“please use it sparingly. The overall AI users have moved out of the forgiving phase, and now they expect to know what is happening.”

▶ watch at 10:29
05The BFF absorbs model output so the client stays dumb and safe

A backend-for-frontend (BFF) sits between the streamed model output and the client, doing more than layout: it hydrates each element with action payloads (tap behavior, deep links, impression metrics) and carries conversational context across turns. He recommends reusing an app's existing UI components (the same flight row, product card) through this layer rather than building a separate agentic look, so the result feels native to the existing app.

“The BF BFF doesn't just ship layout. It does a little more. In addition to the format and context, it does the hydration and adds actions.”

▶ watch at 12:01

“You can reuse the existing CX units you already have. The flight row, the product card, the components your app already shipped in production.”
