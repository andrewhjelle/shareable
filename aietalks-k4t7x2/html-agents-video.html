HTML Is All Agents Need

SpeakerJames Russo · HeyGen Watchyoutu.be/Cz4v1WHVyZc
Generative mediaCoding agents

If you only read one thing

  • HeyGen bet that HTML, CSS, and JavaScript, being the LLM's native training format, produce better agent output than custom DSLs or JSON, and found the thinnest HTML wrapper won over heavier frameworks like Remotion (c1, c3, c9).
  • Hyperframes renders deterministic video by freezing the browser clock and seeking frame by frame through the page (c4).
  • The open-source framework has been used at meaningful scale (1.3M videos in 90 days, 267,000 creators, 32,000 GitHub stars), though the speaker says models still aren't good at creative work on their own (c5, c6, c7).
01The bet: let LLMs speak their native language

HeyGen's premise is that HTML, CSS, and JavaScript are the native languages of LLMs because most of their training data is scraped webpages, so asking a model to output a custom DSL or JSON schema is like asking it to write in a foreign language.

“Our bet is on HTML. HTML, CSS, and JavaScript are the native languages of LLMs.”

“we like to think of this as trying to ask Shakespeare to write a poem in Japanese or Chinese”

▶ watch at 02:41
02What they tried before landing on HTML

The team evaluated After Effects/Premiere (high quality, not agent-friendly), Lottie/Rive (JSON/XML formats, not the model's native tongue), and Remotion (good coding output, but required teaching the model a framework and a lot of examples, which took away creativity). They started testing with a small model, Gemini 3 Flash, on the theory that if a small model could author working code in a format, larger models could too, and found the thinnest wrapper around plain HTML with a few data attributes won.

“we had to teach them the framework. We had to teach them the language and give them a bunch of examples on how to write code properly, which ultimately took away a lot of the creativity of it”

▶ watch at 04:14

“the thinnest wrapper ultimately won, which is essentially just HTML at the end of the day with a few data attributes as metadata”

▶ watch at 05:48
03Turning a browser render into a deterministic video

Because browsers load assets and fonts asynchronously, HeyGen's Hyperframes renderer freezes the browser clock and seeks deterministically to every frame, waiting for the page to fully load before taking a screenshot, then advances to the next frame and repeats until it has all frames to encode into a video.

“We freeze the clock in the browser and then we seek deterministically to every single moment in time or every single frame”

▶ watch at 07:53
04Scale and an open admission

Hyperframes is open source and reports 1.3 million videos rendered by open-source users in the last 90 days, 267,000 creators who have tried it, about 15,000 videos rendered daily, and 32,000 GitHub stars. The speaker states plainly that models still aren't good at creative work on their own, and that getting great (not just decent) output still requires craft and iterative work similar to pre-AI software engineering.

“Over 1.3 million videos have been rendered by open-source users of Hyperframes in the last 90 days.”

Commentary (ours)

(ours) The scale numbers are self-reported and unaudited, and the Remotion/Lottie comparisons come from HeyGen's own internal evaluation rather than a published benchmark, so the 'HTML wins' conclusion should be read as one team's experience rather than a general result.
