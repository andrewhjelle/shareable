State of the Claw

SpeakerPeter Steinberger Watchyoutu.be/zgNvts_2TUE · 44 min SourceRecording of this talk at AI Engineer (2026), published on YouTube by the conference. Quotes are verbatim from the talk transcript with the time they were said.

Gives raw numbers for reading the security posture of a fast-growing, community-run open agent project before deciding whether to run it: 1,142 advisories at 16

If you only read one thing

  • OpenClaw is five months old, has the largest GitHub star count of its kind, about 30,000 commits, and is closing in on 2,000 contributors.
  • It has received 1,142 security advisories (about 16.6/day, 99 critical, ~469 published, 60% closed) -- roughly twice the rate of the Linux kernel or curl -- and Steinberger's heuristic is that the more dramatically a report screams severity, the more likely it's low-quality; concrete examples include Nvidia's Codex security finding 5 sandbox-escape routes in NemoClaw within half an hour, and a CVSS-10 bug where a read-only synced iPhone-app permission could escalate to write access.
  • Defenses include marking external content as untrusted to blunt prompt injection and a reputation-based trust system that grants more privileged access over time; a newer 'dreaming' feature consolidates session memory into long-term storage, loosely modeled on how sleep consolidates human memory.
▣The system in one picture (ours, from the slides and the transcript)

The advisory flood looks alarming until Steinberger's slop heuristic and two concrete bugs are weighed against the defenses OpenClaw already ships; whether that balance holds under sustained attack is untested here (ours).

04Defenses: untrusted-content marking and reputation-based trust

Defenses: untrusted-content marking and reputation-based trust

  • On prompt injection, Steinberger says content arriving from a website or email is marked as untrusted, making exfiltration hard from that path alone, though risk remains if an attacker has unlimited direct access to bombard the agent.
  • In the AMA, Swix notes OpenClaw implements the same kind of trust system as other agent projects: reputation builds over time, and more trusted entities get more privileged access, which Steinberger confirms is part of the story.

Commentary (ours)

The comparison to the Linux kernel and curl's advisory rates is Steinberger's own framing and doesn't control for differences in report quality, project maturity, or how each project's disclosure process works, so the 'twice the rate' figure is best read as his talking point rather than an apples-to-apples security benchmark (ours).
