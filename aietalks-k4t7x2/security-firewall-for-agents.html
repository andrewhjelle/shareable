Security Firewall for Agents

SpeakerRyan Dahl · Deno Watchyoutu.be/MkRYPFIMCSA
SecurityAgentic engineering

If you only read one thing

  • Every action an agent takes, malicious or benign, ultimately reaches the outside world as network bytes — that's the real control point, not the agent's file system access. (c2,c3)
  • Model alignment (Opus refusing harmful commands) and ACL/MCP-based permissions aren't sufficient on their own; composing access across systems reopens holes. (c1,c4)
  • Deno's answer is Claw Patrol, an open-source MIT proxy that parses agent traffic below the HTTP layer against a roughly 1,000-line HCL rule file, and it blocked a live demo attempt to drop a database table. (c5,c6,c8)
01Alignment alone is not security

Dahl's team runs agents (including OpenClaw) with rewrite access to production systems like Postgres, Kubernetes, and AWS to resolve incidents. Opus reliably refuses to run destructive commands when asked directly, but agents connected to support systems can be prompt-injected from the outside, so alignment can't be the only line of defense.

“Security can't just be wishful thinking that Opus will always obey your your wishes.”

▶ watch at 03:08
02Every action is bytes on the wire

Because agents run on standalone, isolated VMs, Dahl's team isn't concerned with file-system access. What matters is that every action an agent takes, good or bad, ultimately takes the form of network communication — bytes going out over the wire, whether via MCP, HTTP, or a spawned subprocess like psql.

“effectively every nefarious action that that an agent could take every good action that it takes comes in the form of some network communication”

▶ watch at 04:09

“We run agents and I assume many of you do the same on standalone VMs.”

▶ watch at 03:39
03Why ACLs and MCP tools fall short

Careful credential provisioning and MCP tool permissions help, but they require managing many systems in precise detail, and composing access across systems (reaching one service, then tunneling to another) can reopen security holes even when each system individually looks locked down.

“the composition of access can lead to holes when you can access one system and then another system.”

▶ watch at 06:44
04Claw Patrol: a byte-level proxy

Deno's response is Claw Patrol, an open-source MIT-licensed proxy that sits in front of agents and inspects traffic below the HTTP layer, parsing protocols like Postgres directly rather than treating everything as generic HTTP requests. Rules are defined in a single HCL configuration file roughly a thousand lines long that the team manages under precise change control. In a demo, an agent told to drop the users table spawned a psql subprocess, and Claw Patrol parsed the Postgres protocol and rejected the destructive action.

“it operates not at the HTP level but at a lower level. It understands each and every bite flowing through flowing out of your agent.”

“it's it's a big long file. It's like a thousand lines and you know we we manage each and every change to that in in kind of precise detail.”

05Will smarter models fix this?

Asked whether the problem shrinks as models get smarter, Dahl predicts agents will never be fully trustable even as alignment improves, meaning backstop security mechanisms outside the agent will always be necessary.

“I think we can we will never be able to fully trust uh AIs.”
