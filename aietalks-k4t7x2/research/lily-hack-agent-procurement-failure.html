Anthropic And OpenAI Just Admitted The Model Isn't Enough.

01What happened at Lily

Security firm Code Wall used a $20, 2-hour autonomous agent with no credentials to get read/write access to McKinsey's Lily platform, used daily by 70% of its 40,000 consultants, exposing tens of millions of chat messages and every governing system prompt. The exploit itself was ordinary SQL injection, but 22 of Lily's roughly 200 API endpoints -- including the writable one -- shipped with no authentication at all, which Jones reads as a pattern rather than one engineer's mistake.

“$20, 2 hours, to get full read and write access to the AI platform that 70% of McKinsey's 40,000 consultants use every single day.”

02Why the old procurement sequence breaks for agents

Jones describes the standard enterprise software buying sequence -- strategic decision, procurement, security review, IT integration, then developers build -- as workable for bounded SaaS tools but broken for agents, which cross permission boundaries a human user's screen would otherwise hide. He argues implementation questions aren't downstream of strategy for agent purchases; they are the strategy, because if the agent can't authenticate or be audited, the roadmap doesn't work regardless of what was signed.

“Strategic decision at the top, procurement negotiates the contract, security and compliance review, IT plans and integration, developers build against whatever platform already got purchased.”

▶ watch at 05:41
03Two questions before you sign or ship

Jones proposes asking whether a platform distinguishes a human user's access from an AI agent's access, since without that boundary one exposed account becomes a company-wide event rather than a contained incident. He pairs that with a control test: can someone revoke a specific agent's access from a console within 5 minutes, not file a ticket or wait for a deploy.

“does your AI platform really know the difference between a human user and an AI agent?”

“one incident becomes a company-wide exposure event. That is not an IT problem, right? That's a board-level liability conversation.”

04Vendors are already selling the fix

In the same week, Jones notes Anthropic and OpenAI both stood up enterprise services arms to embed engineers in customer build rooms, alongside SAP's Dremio/Prior Labs acquisitions, Pinecone's Nexus, Salesforce's Headless 360, and ServiceNow's Action Fabric -- six announcements he reads as one signal that reachable, governed, auditable data access was missing from most AI roadmaps.

“Anthropic and OpenAI have both stood up enterprise services companies with billions of dollars behind them to put engineers inside customer build rooms”

▶ watch at 09:13
05The recommended fix

Jones's concrete recommendation is to move the technical/architectural review earlier in the buying or build process, giving developers more influence over timeline and deployment decisions rather than bringing them in after a platform is already selected.

“the cheapest thing you can do this quarter is to move the technical developer review”
