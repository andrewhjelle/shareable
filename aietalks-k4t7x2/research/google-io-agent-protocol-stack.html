If you only read one thing

  • Six agent protocols are competing to define the 'agent stack': MCP, A2A, and AGUI are consolidating into the real stack; A2UI, AP2, and x402 remain narrower or contested.
  • MCP has scaled to 14,000+ servers but was built for a high-trust environment; Invariant Labs' 'tool poisoning attacks' show it needs real scopes, approvals, and audit trails, not just adoption.

03A2A and AGUI: delegation and control

A2A's core primitive is the agent card, a published description of what a remote agent does and how to reach it, acting as a first operating contract between agents. AGUI, Jones argues, is really about establishing human trust and control over long-running, non-deterministic agents, not just rendering interfaces — an agent that can't show its work becomes 'supervision debt' for the human overseeing it.

04Payments: AP2 vs x402

Two separate payment protocols are piling up on top of the core stack. AP2, Google's agentic-payments protocol with 60-plus collaborators including Amex, Mastercard, and PayPal, centers on a cryptographically signed 'mandate' proving what a user authorized. x402, Coinbase's HTTP-native protocol adopted by Cloudflare, lets an agent pay per API call or resource without an account.
