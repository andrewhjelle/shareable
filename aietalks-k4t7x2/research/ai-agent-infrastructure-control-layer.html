These 5 Infrastructure Giants Secretly Rule AI

SpeakerNate B Jones · Nate B Jones Watchyoutu.be/woGB2vr5wTg
AgentsAI industryBusiness & strategy

If you only read one thing

  • Infrastructure vendors outside the model layer -- Cloudflare, AWS, Auth0, Snowflake, Stripe, Datadog -- decide whether an agent actually reaches production, not OpenAI or Anthropic. (c1)
  • Runtime control points like Cloudflare's durable objects and AWS Bedrock Agent Core give agents memory, scheduling, and execution that a stateless model call doesn't have. (c2, c3)
  • A real kill switch has to work at the runtime, identity, and payment layers at once -- telling the model to stop isn't a kill switch. (c9)
01The layer under the model that decides if agents ship

Jones argues compute and the model are necessary but not sufficient for a full agentic economy: once agents start doing real work, the next bottleneck is whether the agent is governable -- where it runs, what it remembers, who it acts for, what it can spend, and who can stop it. He says those questions get answered by infrastructure, not by the model itself, and names Cloudflare, AWS, and Vercel as the runtime control-point layer sitting under the agent protocols.

02Who the agent is allowed to act as

Jones covers the identity control point -- Auth0, Okta, WorkOS, Microsoft Entra Agent ID, and AWS Agent Core Identity -- as the layer that decides what an agent is authorized to do on a user's behalf. He describes Auth0's approach as delegated authority with constraints: an agent calls APIs on behalf of a user rather than holding a broad standing credential, and rag queries only retrieve documents that user is authorized to see.

“An agent does not get a broad permanent credential just because”

03What the agent is allowed to know

Jones frames the data control point -- Snowflake and Databricks -- as governing which data an agent can safely interpret, since a generic agent can join the wrong tables, misread a metric, or answer confidently from ungoverned context. He describes Snowflake's Cortex Agents as routing between a structured-query tool and an unstructured-retrieval tool, both operating inside Snowflake's governance perimeter, with Databricks' Mosaic AI framework and BigQuery/Gemini making a similar move inside their own platforms.

04Who processes the money

Jones says the moment an agent touches money, control becomes critical, and positions Stripe as the default operator because it already sits across payment credentials, fraud, disputes, billing, subscriptions, and merchant onboarding -- not because of any single protocol. He contrasts this with the card networks (Mastercard, Visa, American Express), which he says are competing to prove an agent transaction can clear the same institutional trust chain as a normal card transaction, on their own rails.

05Watching agents and being able to stop them

Jones distinguishes agent observability from ordinary logging, arguing agents fail in ways plain logs won't catch -- calling the wrong tool with valid syntax, or completing a task while violating intent. He points to Datadog's LLM observability as tracing a full agent run end-to-end, and separately argues a kill switch is a product feature that must work at more than one layer: runtime cancel, identity revoke, gateway block, and payment freeze, not just telling the model to stop.
