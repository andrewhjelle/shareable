Don't be data poor

SpeakerAnuj Iravane · Anterior Watchyoutu.be/XAsb7MIAzm8

01The problem: rich data you can't keep

Anterior builds clinician-led AI agents for health plans, automating high-stakes administrative workflows like prior authorization, payment integrity, and HEDIS measures. The source data is scanned fax bundles of medical records (Anuj states about 70% of medical communication still happens via fax) that are information-dense but highly variable in format. Because this data is PHI, Anterior's contracts prohibit retaining it, reusing it, or even keeping redacted or anonymized derivative copies.

02Why one-shot LLM generation fails

Healthcare accuracy bars are exceptionally high, so a 95% eval score isn't sufficient reassurance. Trying to have an LLM generate a full synthetic medical record in one shot runs into a mode-collapse problem: the outputs lack diversity, partly because this data source is underrepresented in pretraining corpora and partly because pretraining/post-training objectives optimize for helpfulness, not creativity.

“the the baselines for accuracy are just exceptionally high. 95% is not good enough”

▶ watch at 02:03

“LLMs seem to suffer from this very strange mode collapse problem when it comes to generating like diverse uh data, creative data”

▶ watch at 04:07
03The reverse-generation pipeline

Instead of running the forward task (unstructured data plus policy leads to a reasoning trace and a label), Anterior reverses it: sample a random label, derive a reasoning trace for that label from a symbolic decision-tree representation of the policy, then generate the medical record backward from that trace, layer by layer (patient invariants, then a patient journey of events, then per-encounter documents).

“can we actually start by sampling a random label, uh figuring out a a reasoning trace for that label, and then trying to generate data backwards from that”

▶ watch at 05:39
04Clinicians own the pipeline

Every stage of the generation pipeline runs as a skills-based workflow on an internal agent harness, so clinicians can interject at any point to steer output toward cases they've seen in production, and can add a new document type by writing a new skill file rather than requesting an engineering change.

“you want your domain experts to be the ones telling you what's good, what's not good”

▶ watch at 11:51

“it's really important to give your domain experts the keys because these are the people who know”

▶ watch at 15:33
05Results

Roughly 90% of Anterior's datasets are now synthetic, and in a blind review clinicians could distinguish synthetic from real records only about 60% of the time. The talk closes with a set of takeaways: reverse the inference workflow, sample diversity from an appropriate distribution, emulate the real data-generation process, and give domain experts ownership of the pipeline.

Commentary (ours)

The reverse-from-label approach is a clean way to sidestep the diversity problem, but it only generates data for evaluation so far, not training — Anuj is explicit that this is the current scope, which tempers how far the 90%-synthetic and 60%-indistinguishable numbers should be read as validation of the whole pipeline (ours).
