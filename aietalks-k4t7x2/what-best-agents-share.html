What the Best Agents Share

takeAgentic engineeringProduct & UX

Names four concrete UX patterns (focus modes, transparent execution, personalization, reversibility) drawn from Cursor, Claude, Manifold, and Harvey, usable as a checklist when designing or evaluating an agent product's interface

If you only read one thing

  • Best agents share four patterns: focus modes, transparent execution, personalization, and reversibility, illustrated with Cursor, Claude, Manifold, and Harvey (c1, c3, c5, c7).
  • Focus modes narrow the action space so engineers can tune quality and users know what to expect, as in Cursor's distinct planning and debug modes (c1, c2).
  • Reversibility (line/file/conversation-level undo, parallel multi-model outputs) bounds the downside of agent mistakes and makes users more willing to delegate higher-value tasks (c7, c8).

The talk argues four UX patterns compound into trust: constraining scope and showing work let a user verify an agent, while reversibility is what actually removes the risk of acting on that trust (ours).

Focus modes constrain the action space

  • Focus modes put an agent into a specific mode (e.g., planning or research) that constrains its action and input space, letting engineers tune tools, prompts, and evals for that narrower task and setting clearer expectations for users.
  • Cursor's planning mode, for example, deliberately writes no code and only produces a plan and clarifying questions, while debug mode uses a hypothesis-driven approach with a dedicated debug server.

Transparent execution turns delegation into collaboration

  • Making an agent's process, tool calls, and assumptions visible shifts the interaction from pure delegation to collaboration, building trust in the eventual output because the user can see what was read and assumed along the way.
  • It also lets users intervene earlier if the agent goes off track, reducing wasted work; Claude and Manifold both surface progress lists showing completed and pending steps.

“The crux of what we're trying to achieve here is to shift from uh delegation to collaboration”

“it also enables the user to intervene at an earlier point in time if it sees the agent is really doing the wrong thing”

03Personalization optimizes for speed to understanding
Slide at 05:50 · click any slide to enlarge · 4 more from this section below

Personalization optimizes for speed to understanding

  • Personalization means giving an agent the thoughts, systems, and principles a user would apply themselves, aiming to increase the agent's speed to understanding rather than just speed to output.
  • Harvey's 'playbooks' let legal teams encode the methods they use to review a contract so the agent applies the same approach, alongside memory and Claude's skills/connectors as other personalization mechanisms.

“they optimize for speed to outcome, but not speed to understanding”

said at 05:44

“the methods and principles that they use to, for example, uh review a certain contract”

04Reversibility bounds the cost of mistakes
Slide at 07:50 · click any slide to enlarge · 8 more from this section below

Reversibility bounds the cost of mistakes

  • Reversibility -- the ability to undo an agent's actions -- binds the downside cost of a mistake, which makes the ROI calculation easier for users and makes them bolder about handing over higher-value tasks.
  • Cursor implements this at multiple levels of granularity: line-level accept/reject, file-level rollback, and jumping back to earlier points in a conversation, plus running multiple models in parallel and keeping only the best output.

“the big thing that we are achieving from this is we're binding the cost of our mistakes”

said at 07:49

“you can actually roll back or or choose on a line level what you want to accept or reject based on what the agent did”

said at 08:22

Commentary (ours)

The framing implies reversibility is the pattern that unlocks the other three: transparency and personalization only help a user trust an agent's judgment, but reversibility is what removes the actual risk of acting on that trust before it's fully earned (ours).
