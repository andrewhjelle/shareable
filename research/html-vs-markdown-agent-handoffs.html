04The HTML-vs-markdown fight

The HTML-vs-markdown fight

  • Anthropic's Tariq Shay Haddad's essay 'The Unreasonable Effectiveness of HTML' argues HTML can represent almost any information Claude produces more efficiently for human review than markdown can.
  • The pushback, voiced by commenters like Josh Dawes, is that HTML costs more tokens; The Smart Ape's follow-up post proposes picking format by three questions (audience, edit lifecycle, time horizon) rather than treating it as either/or.

05NLW's read: the job has shifted to staging work

NLW's read: the job has shifted to staging work

  • Whittemore argues the deeper shift behind the format debate is that in the agent era the operator's job is increasingly to stage the conditions for an agent to do the work, not to produce the final output directly.

“My argument is that in the agent era, the atomic unit of knowledge work has shifted.”

said at 18:44

Commentary (ours)

(ours) The format debate and Whittemore's staging-work thesis are really two claims about the same underlying change: as more of the actual production work moves to the agent, the artifact a person writes (markdown or HTML) is judged less on its own merits and more on how well it constrains or frees the agent that reads it next.
