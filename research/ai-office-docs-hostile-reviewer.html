If you only read one thing

  • AI can now draft multiple full Office documents at once, but a document that looks finished (right layout, right labels) can still have wrong underlying formulas that Excel won't flag with a ref error (c1, c2, c3)
  • The fix is a four-stage workflow -- prepare sources into an indexed packet, produce a file spec before any slide/formula exists, build the artifact constrained to that spec, then run a hostile-reviewer AI pass that only enumerates problems and isn't allowed to fix them (c4, c5, c6)
  • Task risk varies by type: lowest for formatting/layout, medium for source attribution and data extraction, highest for financial calculations and claims that travel to senior leadership -- illustrated by the publicly wrong chart from the ChatGPT-5 launch (c7, c8)

03The four-stage workflow

The four-stage workflow

  • His fix is to treat office-file generation as a workflow, not a single prompt: (1) prepare an organized, indexed packet of sources rather than asking directly for the deck; (2) produce a file specification -- a narrative spine and slide list for a deck, a tab architecture and calculation flow for a workbook -- before any content is generated; (3) build the artifact constrained to that source packet and spec; (4) verify with an aggressive reviewer pass.

“workflow world, not a prompt world. So for Office files, that workflow has four”

said at 03:32
04The hostile-reviewer prompt

The hostile-reviewer prompt

  • For verification he uses a second model (Opus 4.7 reviewing output built with Codex) with an explicit prompt: read the deck or workbook as a skeptical reviewer who suspects every claim and number, and flag claims without source attribution, untraceable chart data, inconsistent formulas, and assumptions presented as facts -- without fixing anything, only enumerating.
  • He then pipes the edit list back to the generating model in a loop he calls a 'Ralph loop.'
